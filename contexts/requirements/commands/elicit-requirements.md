# Elicit Requirements

## Intent

Discover and structure stakeholder needs, outcomes, constraints, rules, and open questions.

## Invocation

This command is an engineering-intent entry point. It selects the responsible specialist and workflow; it does not duplicate their procedure.

## Uses

* Agent: `contexts/requirements/agents/requirements-analyst.md`
* Skill: `contexts/requirements/skills/elicit-requirements.md`

## Inputs

* Available stakeholder or project context.
* Existing evidence and source material.
* The requested problem, initiative, or scope.

## Output

A requirements elicitation handoff conforming to `contracts/requirements-workflow.md`.

## Boundary

If required evidence is materially ambiguous or insufficient, return the clarification need rather than inventing intent.
