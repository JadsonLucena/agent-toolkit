# Specify

## Purpose

Entry point for converting sufficiently understood needs into a precise, verifiable, traceable requirement specification.

## Uses

* Agent: `contexts/requirements/agents/requirements-specifier.md`
* Skill: `contexts/requirements/skills/definition/skill.md`
* Rule: `contexts/requirements/rules/requirements.md`
* Contract: `contracts/requirement-specification.md`

## Inputs

Elicitation evidence, existing requirements, governing constraints, domain context, and explicit decisions.

## Result

A requirement specification with requirements, acceptance criteria, business rules, constraints, assumptions, dependencies, traceability, and unresolved questions.
