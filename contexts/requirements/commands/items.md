# Items

## Purpose

Entry point for producing a structured backlog from sufficiently defined requirements and other explicit work sources.

## Uses

* Agent: `contexts/requirements/agents/backlog-planner.md`
* Skill: `contexts/requirements/skills/planning/skill.md`
* Rule: `contexts/requirements/rules/planning.md`
* Contract: `contracts/backlog-item.md`

## Inputs

Requirement specifications, defects, risks, decisions, constraints, and the intended planning horizon.

## Result

Traceable work items with coherent intent, acceptance evidence, dependencies, risks, assumptions, blockers, and readiness state.
