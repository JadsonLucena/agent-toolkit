# Refinement

## Purpose

Entry point for improving an existing backlog without changing the semantics of its source requirements.

## Uses

* Agent: `contexts/requirements/agents/backlog-planner.md`
* Skill: `contexts/requirements/skills/planning/skill.md`
* Rule: `contexts/requirements/rules/planning.md`

## Inputs

Existing work items, their source evidence, new validated requirement information, and the intended planning horizon.

## Result

Refined work items with improved clarity, decomposition, traceability, dependencies, risks, blockers, and readiness information. Material semantic changes are returned to requirements definition.
