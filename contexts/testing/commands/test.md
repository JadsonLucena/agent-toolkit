# Test

## Purpose

Entry point for creating or modifying automated tests for a defined behavior or implementation scope.

## Uses

* Agent: `contexts/testing/agents/test-engineer.md`
* Skill: `contexts/testing/skills/generate-tests/skill.md`
* Rule: `contexts/testing/rules/testing.md`

## Inputs

* Behavior or implementation under test.
* Optional target scope.
* Optional requirement specification, acceptance criteria, or `contracts/test-basis.md`.
* Project testing conventions and verification constraints.

## Result

Tests, test strategy, verification evidence, and material blockers or uncertainty.

Requirements artifacts are optional evidence. This command does not depend on Requirements agents or skills.
